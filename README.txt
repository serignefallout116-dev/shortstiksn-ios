# SHORTSTIKSN — prototype v1

Prototype responsive web/PWA de démonstration utilisant le logo fourni.

## Lancer
- Ouvrir `index.html` dans un navigateur pour tester l'interface.
- Pour tester l'installation PWA, héberger le dossier sur un hébergement HTTPS.
- Sur iPhone : ouvrir le site dans Safari > Partager > Sur l'écran d'accueil.
- Sur Android : ouvrir le site dans Chrome > Installer l'application / Ajouter à l'écran d'accueil.

## Fonctions de démonstration
- Interface mobile et desktop rouge/noir/blanc.
- Fil vidéo de démonstration.
- Ajout local d'une vidéo depuis l'appareil (non envoyé à un serveur).
- Likes, suivre/ne plus suivre, recherche, partage natif si disponible.
- Navigation de base.

## Limites importantes
Ce prototype n'est pas encore un réseau social public en production. Il n'y a pas de backend, de comptes sécurisés, de base de données, de diffusion vidéo distante, de vrais commentaires/messages, de live streaming, de notifications push, de modération automatisée ni de publication sur App Store / Google Play.

## Étape de production nécessaire
Construire une application mobile multiplateforme (par ex. React Native/Expo) et un backend sécurisé avec authentification, base de données, stockage/transcodage vidéo, flux de recommandation, messagerie temps réel, live streaming, signalement/modération, protection des mineurs, règles de confidentialité et infrastructure évolutive.
